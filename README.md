# ⚡ Ohm's Law & Electric Power Calculator (欧姆定律与电功率万能计算器)

> 🔬 A production-grade, FormulaCalcKit-styled electrical engineering suite featuring Ohm's law permutations, series/parallel circuit simulation, resistor color code decoding, electricity cost calculation, and wire sizing.
>
> 专为物理教育、电子 DIY 与电气工程打造的现代化万能计算套件，极简高质感设计，支持中英双语、分步推导与安全规格匹配。

---

## ✨ Features (核心特性)

- ⚡ **Ohm's Law & Power Solver (欧姆定律与电功率推导)**: Enter any 2 quantities ($U, I, R, P$) to solve all remaining variables with step-by-step rigorous algebraic formulas and SI unit verification.
- 🔌 **Interactive Circuit Solver (串并联电路仿真器)**: Dynamic schematic simulation for series, parallel, and voltage divider circuits with real-time overload monitoring.
- 🎨 **Resistor Color Code Decoder (色环电阻解码器)**: Decode 4-band and 5-band resistors with visual bands, tolerance calculation, and reverse value-to-color lookup.
- 💡 **Electricity Cost Calculator (用电度数与电费核算)**: Estimate kilowatt-hours (kWh), carbon emissions, and electricity bills with common household appliance presets.
- 📐 **Wire Gauge & Safety Breaker Sizing (铜线载流量与空开匹配)**: IEC 60364 & GB standard safe current capacity table for $1.5 \sim 10\text{ mm}^2$ (16 ~ 8 AWG) copper conductors.
- 🌐 **SEO & Google Indexing Ready (全站搜索引擎优化)**: Pre-configured `robots.txt`, `sitemap.xml`, OpenGraph cards, and Google Schema.org (`WebApplication`, `FAQPage`, `HowTo`, `BreadcrumbList`).
- 📢 **Smart Ad & AdSense Ready (智能广告自适应槽位)**: Built-in `AdSlot` component with Core Web Vitals zero CLS (Cumulative Layout Shift) prevention.

## 🚀 Quick Start (快速开始)

```bash
# Clone the repository
git clone https://github.com/laohu90/ohms-law-calculator.git
cd ohms-law-calculator

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
